# JurisWire Website Prototype

This is a responsive front-end prototype for **JurisWire — Law • Courts • Justice**.

## Included
- `index.html` — legal news homepage
- `legal.html` — JurisWire Legal professional-practice section
- `article.html` — article / case explainer template
- `judgment.html` — searchable judgment database prototype
- `styles.css` — responsive black/white/deep-red/gold design system
- `script.js` — mobile navigation, prototype judgment filtering, demo forms

## Production implementation requirements
This prototype is static. A production build should connect it to a CMS/backend such as WordPress with a custom lightweight theme or a modern headless CMS.

### Recommended content models
- News Article
- Live Update / Live Blog
- Judgment
- Court
- Judge
- Act
- Section
- Legal Subject
- Editorial Author
- Legal Professional
- Practice Area
- Digest

### Production integrations
- Google Analytics 4
- Google Search Console
- Google News sitemap
- NewsArticle / Article / Breadcrumb / Organization / Author schema
- Newsletter provider
- WhatsApp Channel CTA
- Push notifications
- AdSense / Google Ad Manager
- CDN / caching / image optimisation
- 2FA, firewall, backups, activity logs

### Governance / compliance
Keep **JurisWire News** editorial content clearly separated from **JurisWire Legal** professional-practice content. Final legal-practice wording and disclaimers should be reviewed for compliance with applicable Bar Council rules before publication.

## How to preview
Open `index.html` in a browser. No build step is required.
